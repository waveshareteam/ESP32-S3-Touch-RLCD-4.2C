# 应用顶栏

[English](README.md) | [简体中文](README_ZH.md)

## 功能

共用 400×48 白色顶栏，使用黑色标题、图标及描边返回按钮，底部分隔线搭配红色短条，供天气、音乐、2048、相册、传感器、设置、按键和麦克风测试使用。

## 硬件

ESP32-S3-Touch-RLCD-4.2C，400×300 黑白红三色 ST7306 屏幕。

## 使用

持有 LVGL 锁时调用 `rlcd_app_header_create()`，传入应用现有返回回调。正文从 y=48 开始；全屏相册及屏幕测试保留各自布局。

## 预期效果

32×32 I1 图标保持原生尺寸，白底黑色图案。`rlcd_ui_primary_button()` 将主按钮设为红底白字，按下时黑底，禁用时白底黑字。`rlcd_ui_secondary_button()` 使用白底、黑色描边与文字，按下时黑底白字。

## 说明

控件随父对象释放。本组件不新建任务、不访问外设、不持有导航状态，事件仍由各应用处理。
